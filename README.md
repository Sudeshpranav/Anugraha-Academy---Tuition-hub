# Anugraha Academy — Tuition Hub

A modern, responsive, bilingual (English & தமிழ்) tuition centre web application for **Anugraha Academy — Tuition Hub** in Chennai.

---

## 🚀 Development & Build

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview build
npm run preview
```

---

## 🌐 Deployment
Configured for zero-config deployment on **Vercel** (`vercel.json`) and **Netlify** (`netlify.toml`).
